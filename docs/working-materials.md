# Afterburn Skies — рабочие материалы

## Структура проекта

- `index.html` — командный центр и дашборд GitHub Pages.
- `mockups/` — интерактивные макеты экранов.
- `data/planes.json` — данные самолётов для дашборда.
- `data/roadmap.json` — прогресс и этапы.
- `data/updates.json` — ручной changelog проекта.
- `docs/game-design.md` — дизайн игры.
- `app.js` — загрузка данных и проверка новых GitHub-коммитов.

## Как работает блок «Новое»

Сайт делает две проверки:

1. Загружает `data/updates.json`, чтобы важные материалы отображались даже без API.
2. Проверяет последние публичные коммиты репозитория через GitHub API. Если появился новый commit, на дашборде показывается зелёное уведомление.

Просмотр сохраняется в `localStorage` браузера. После нажатия на галочку уведомление скрывается до следующего изменения.

## Как добавлять новое

После добавления макета или документа:

1. Добавить запись в начало `data/updates.json`.
2. Обновить дату в `data/roadmap.json`.
3. Сделать commit с понятным сообщением, например `Add flight HUD mockup`.
4. Отправить commit в GitHub.

Даже если запись в changelog забыта, новый commit всё равно будет найден через GitHub API.
