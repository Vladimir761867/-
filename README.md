# Afterburn Skies

**Форсаж Небес** — простой аркадный проект про полёты, воздушный бой и трюки.

## GitHub Pages

Включите Pages для ветки `main`, папка `/ (root)`. После публикации сайт будет доступен по адресу:

`https://vladimir761867.github.io/Afterburn-Skies/`

Командный центр автоматически показывает данные из `data/` и проверяет последние коммиты репозитория через GitHub API.

## Игровой прототип

Рабочий первый вылет находится в [`game/`](game/) и публикуется по адресу:

`https://vladimir761867.github.io/Afterburn-Skies/game/`

В прототипе проверяются ангар, брифинг, управление пальцем, цели, огонь, ракеты, трюки, кольца, энергия и экран результата.

## Быстрый просмотр локально

Откройте `index.html` через любой локальный статический сервер, чтобы загрузка JSON-файлов работала корректно.
